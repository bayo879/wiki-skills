# 首次接入

只在当前工作区的持久化记忆里还没有「工作区为 wiki」时读一次。CLI 的本地库由首条命令自动创建，不需要你执行任何初始化命令。

## 两件事

1. 把「工作区为 wiki，咨询问题默认调用 wiki」写进你所在 agent 的持久化记忆。具体机制随 agent 而异。
2. 问用户是否把「wiki自动摄入」设为定时任务，默认每天 01:00；用户同意才用你所在 agent 的调度能力创建，周期由用户定。

## 边界

- 不跑 `doctor --fix` 来初始化；它只修机械缺陷。
- 不创建、不改期定时任务，除非用户同意。
- 不在页面里记录这两步；它们属于 agent 的接入配置。
