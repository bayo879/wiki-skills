# note：零散要点

只写 `template.body`，章节只有「要点」，不要改名或加 `###`；
frontmatter、`## 关联`、`## 证据` 都由引擎按载荷生成。

- 要点：3–5 条 bullet，一条一个事实，不写成段落。

## 示例

```markdown
## 要点

- 主题：“双零”行动，即零重大故障、零重大安全事件。
- 阶段：宣传动员、排查整治、总结提升。
- 抓手：建立问题清单，实行销号管理。
- 定位：安全是底线，业务发展不能以牺牲安全为代价。
- 与火灾隐患排查同属安全生产条线，见 `fire-hazard-inspection-2026`。
```
