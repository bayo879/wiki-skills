# 开发方向与决策

本文件记录用户已确认的方向与关键取舍。新决策由用户拍板后追加；未确认的候选方案写进
`docs/issues/`，不要写在这里。

已定方向速览：

- **skills-only**：技能包只依赖 Python 标准库，安装不装依赖；不做联网抓取、OCR 或向量库。
- **账本是唯一事实源**：页面、raw、证据、任务都在账本里；页面正文只由观看区推送写出，
  不再保留页面镜像。
- **页面三类**（concept / entity / process），raw 是一等对象，证据用标准 Markdown 链接指回
  raw 的逐字引文；关联只连现有页面，由 route 决定，只增不删。
- **工作流与话题定义在观看区**：`<view>/workflows/`、`<view>/topics/` 优先，旧根只读兜底；
  `query` 只给候选，`workflow search` 才做显式检索。
- **任务目录化、单写者**：任务在 `.wiki/tasks/`，租约按会话归属，普通 `query` 走只读快照。
- **实现按职责分模块**：`wiki.py` 只做入口转发，命令、账本、任务分目录，单文件不超过
  1000 行 / 2 万字符。
