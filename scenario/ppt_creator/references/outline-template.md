# 逐页大纲模板

交接给 `pptx` 技能前，每页按这六项写全。缺哪项就补，补不上写“缺依据”。

| 字段 | 写法 | 反例 |
| --- | --- | --- |
| 标题 | 一句话结论，听众看标题就知道这页说什么 | “背景介绍”“方案概述” |
| 结论句 | 这页要让听众记住的那一句，20–40 字 | 把要点重复一遍 |
| 要点 | 3–4 条，每条一行说清，能念得出来 | 整段话贴在页上 |
| 依据 | 页面 id（`page-xxx`）或 `raw:<key>`；多条并列 | “根据相关资料” |
| 图表建议 | 折线 / 柱状 / 表格 / 流程图 / 不用图 | 有数字却只用文字堆着 |
| 口播 | 可选，这页你要多讲的那 1–2 句 | 把要点原样朗读 |

## 正例

```markdown
### 第 3 页：三类工单占了八成，处理时长却差三倍
- 结论句：先把标准件工单自动化，收益最大且改动最小。
- 要点：
  - 标准件、咨询件、投诉件合计占 82% 工单量（依据：page-order-types）
  - 三类平均处理时长分别为 4 分钟、11 分钟、36 分钟（依据：page-order-sla）
  - 标准件流程步骤固定，最适合规则化（依据：page-standard-flow）
- 图表建议：堆叠柱状图，横轴为月份，纵轴为工单量占比
- 口播：观众最容易问“为什么不先做投诉件”，这页要把“量”和“改动成本”一起摆出来。
```

## 反例

```markdown
### 第 3 页：工单现状分析
- 工单类型很多，处理起来比较复杂。
- 各方面都有优化空间。
```

问题：标题不是结论；没有数字；没有依据；听众不知道要记住什么，`pptx` 技能也没法据此排版。

## 自查四问

1. 这页的结论句能单独成立吗？脱离上下文还看得懂吗？
2. 每条要点都有出处吗？出处能落到页面 id 或 raw key 吗？
3. 有数字却没有图，或有图却没说清结论吗？
4. 各页标题连起来读，是一段有推进的话，还是一串并列名词？
